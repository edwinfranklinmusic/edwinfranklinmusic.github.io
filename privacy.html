Privacy Policy

Last updated: 2026-10-18

This policy covers "AI Music Channel", a private tool operated by Edwin Franklin Music. It is used only by the channel owner to manage the Edwin Franklin Music YouTube channel.

What data the app uses

  • With your permission (Google sign-in), the app uses the YouTube Data API to upload videos and set their titles and descriptions, and the YouTube Analytics API to read the channel's own view statistics.
  • The sign-in token is stored only on the owner's own computer. It is not sent to any other server.

Sharing

We do not sell, share or transfer Google user data to anyone. Data is used only to provide the upload and statistics features above. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

The app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access

You can remove the app's access at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer removes all stored data.
